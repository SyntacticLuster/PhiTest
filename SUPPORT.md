# Support

## Bug reports

Open a GitHub Issue using the bug report template. Include:

- ɸTest commit SHA
- Python version and OS
- Protocol and adapter involved
- Steps to reproduce
- Expected and actual behavior
- Relevant sanitized log output

Remove any secrets or private subject/experiment data before posting.

## Feature requests

Open a GitHub Issue using the feature request template. Describe the problem being solved, the proposed behavior, and any scientific or theoretical motivation.

## Protocol and methodology discussion

Open a GitHub Issue or Discussion (if enabled). Frame questions around falsifiable predictions or measurable operational behavior where possible.

## Security vulnerabilities

**Do not use GitHub Issues for security reports.** See [SECURITY.md](SECURITY.md).

## No individual support guarantee

This is an open-source project maintained on a best-effort basis. There is no guaranteed response time.
